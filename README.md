# AdvisoryOS

AI-powered advisory operating system focused on retrieval, workflow orchestration, document analysis, and Telegram-based assistance.

## Overview

AdvisoryOS is a Telegram-first AI operating system designed to support senior advisory work.

The system is being developed to help retrieve relevant information, analyse documents, prepare advisory deliverables, support meetings, and reduce repeated manual work.

## Core Capabilities

- AI Chief of Staff orchestration
- Specialist agent workflows
- Knowledge and document retrieval
- Semantic search and source-aware retrieval
- Telegram-based interaction
- Document analysis
- Meeting preparation
- Meeting action extraction
- Advisory opportunity qualification
- Evidence-aware outputs
- Model and task routing
- Privacy and knowledge governance
- Human approval before external actions

## Architecture

The system is designed around a Chief of Staff orchestration layer with specialist capabilities for retrieval, analysis, document processing, review, and deliverable creation.

The preferred retrieval approach is:

Direct reference → deterministic search → semantic search → agent reasoning

This helps reduce unnecessary model usage and improves reliability.

## Telegram Interface

Telegram is the primary operating interface.

The goal is for users to interact with the system through concise requests such as:

> Find the latest document about this project.

> Review this attached document.

> Compare this with the previous version.

> Prepare me for tomorrow's meeting.

> What actions came out of yesterday's call?
